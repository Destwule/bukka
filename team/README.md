# The team

One file per team member, named after your GitHub username:
`team/<your-github-username>.md`. Adding yours is part of
[BUK-14](../tickets/BUK-14.md).

When your file is merged into `main`, your production branch
`apprentice/<your-github-username>` is created for you automatically.

Copy this template:

```markdown
# Tod Jolayemi

- **GitHub:** @Todjolayemi
- **Based in:** Texas, USA
- **Background:** I've done so many things lol...
- **What I want from this team:** To learn from the best and to network.
- **Ask me about:** Tech, Business, Photography, Lifestyle generally...
```
